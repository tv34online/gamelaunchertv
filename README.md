# ТВ 34 Лаунчер

Android TV лаунчер в стиле Apple TV: 5 фиксированных плиток, обои с r/wallpapers, виджеты (время МСК, «Вы играли», ускорение ТВ).

## Сборка
1. Залей содержимое в репозиторий GitHub (ветка `main`).
2. Вкладка **Actions → Build TV34 Launcher → Run workflow** (или просто пуш).
3. APK: **Releases → latest → TV34-Launcher.apk** (также лежит в артефактах запуска).

## Настройка
- Приложения: `app/src/main/java/ru/tv34/launcher/Apps.kt`
- Сделать лаунчером по умолчанию: после установки нажми кнопку Home и выбери «ТВ 34 Лаунчер» → «Всегда».
